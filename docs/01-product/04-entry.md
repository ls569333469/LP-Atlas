# 购买与开仓页

扫描看板点进某个池子后进入这一页。这一页按可真实上链来设计，不再按「只预览、不出交易」来留接口，免得扫描完成后再打补丁。实现必须等扫描验收通过后再写。

到时候由用户连接钱包并签名提交，产品只组交易，不代持私钥，不保存助记词，不默认自动下单或自动重挂。平台代执行、代付 gas 的开关不作为默认。路由费是他人平台抽成，自托管开仓时不应默认照抄一笔 0.5%。单边挂单（区间全在现价上方或下方，只出一种资产）是正式开仓选项，不是后补。

| 模块 | 怎么设计 | 说明 |
| --- | --- | --- |
| 钱包与网络 | 扫描验收后实现 | 连接钱包并切换到目标链；只对服务端组好的交易请求签名。不代持、不保存私钥或助记词。第一期实现不做这一块，但路由和接口现在就要预留 |
| 只读仓位 | 扫描验收后实现 | 读出钱包在已接入协议上已有的头寸，不限于本产品开过的仓。汇总页对照 Barker 的「我的仓位」与 Revert 的仪表板：展示区间、是否在区间内、库存、未领手续费和估值，可按链和协议筛选；池详情/开仓页同时列出该池下的头寸。同一 EVM 地址在其他已接入 EVM 链上的仓可只读汇总；Solana 仓位须另连 Solana 钱包。加仓、减仓、领费、关闭走同一套签名提交 |
| 区间 | 按可上链设计 | 可选模板：窄区间跟随（1%–2%）、±5% / ±15% / ±30%、自定义上下沿、上方或下方单边挂单；对齐 tick 后显示真实价格，提交时用对齐后的边界 |
| 入场资产与金额 | 按可上链设计 | 只出 U、只出代币、或按区间比例出双资产。缺一边或比例不足时，自动按所需比例找路径兑换再开仓，尽可能组在同一笔、签一次，失败则整笔回退；路径走目标链上已接入协议，找不到就明确失败。授权单独确认，默认按含滑点缓冲的本次预计上限，可选手动开无限授权 |
| 滑点与预期 | 按可上链设计 | 滑点上限可调，默认 0.5%，组交易时写入 `amountMin`；展示流动性份额和当前窗口手续费预估，用来判断够不够付一次调仓成本 |
| 进出纪律 | 写入参数，默认不自动执行 | 默认：出区间就撤。可选：出区间再偏约 1% 后调仓并复投；调仓以该价格条件为准，时间冷却为可调参数且默认 0（不受时间限制）。到价退出、止盈、止损可配置。自动重挂和第三方暴跌代撤默认关闭。自动调仓复投属第四层，须用户另行确认后再实现 |
| 提交 | 扫描验收后实现 | 组 mint 或加仓交易，由用户签名后广播。失败要可见，不得静默重试成第二笔。每次操作有唯一客户端 ID |


## 开仓页交互

开仓页综合 Meteora、Barker、Revert 的界面长处来设计，做成自己的产品。不照抄托管执行、他人路由费或第三方自动再平衡。

| 参考 | 采用 | 不采用 |
| --- | --- | --- |
| Meteora 池页 | 池上下文与开仓表单同页：价格图、流动性分布、选中区间叠加；该池已有头寸列在图下 | 限价单与闪兑作为默认主路径；其自动执行开关 |
| Barker 新建仓位 | 一键配置与自由配置；±5% / ±15% / ±30% 与单边预设；区间同时显示百分比和价格，并标明对齐后的真实边界；到价退出、止盈、止损；单资产或双资产入场 | 路由费、暴跌保护代执行、自动重挂代执行 |
| Revert 创建仓位 | 可拖拽的区间手柄、居中与按百分比微调；显示钱包余额和最大可用；提交前给出预计投入和换后最低数量 | Auto-Range、借贷抵押和回测（无数据时不强做） |

1. 页面分三块：池上下文（交易对、费率档、hook、现价、价格图与流动性分布，选中区间叠在图上）；右侧或下方的开仓表单；若已连钱包，该池已有头寸列在同页，与汇总的「我的仓位」互补。
2. 表单先选模板或一键配置（窄区间跟随、短线收割后撤、宽区间铺现货、两端加厚），再进入自由调整。区间支持预设、上方或下方单边、拖拽手柄和加减百分比，同时显示价格与百分比；提交前对齐 tick，并展示真实上下沿。
3. 金额可只出单边或按比例出双资产，显示钱包余额和最大可用。缺资产则按所需比例自动兑换，预估换后数量写入同一笔交易。
4. 提交前摘要必须可见：流动性份额、窗口手续费预估、预计投入、含滑点的 `amountMin`。滑点可调，默认 0.5%。授权按含滑点缓冲的本次上限，另步确认。
5. 到价退出、止盈、止损在表单里可配置。自动重挂和第三方暴跌代撤默认关闭，不作为默认开关。提交由用户签名，失败可见，不得静默重试成第二笔。

## 入场与离场纪律

入场只看手续费能否覆盖无常损失。价格脱离区间立刻撤池。不要用第三方自动再平衡。交易走私有 RPC，并用 `amountMin` 防夹。

`E[Fee(T)] > IL(ΔP)`

左边是持有区间 T 内预期可收到的手续费，右边是价格变动 ΔP 时的无常损失。公式只比较这两项。入场前要用私有 RPC 重新计算，不能把站上的 APR 当成入准结论。短线 APR 达到 3000% 才打、低于 1000% 是禁区，这是教程里的操作建议，门槛可按实际需求调。
