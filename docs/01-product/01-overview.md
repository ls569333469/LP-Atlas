# 产品概述

> 最新设计：窗口为 1H、2H、4H、6H、24H、3D，小时档保留 4 天；实施状态及旧记录以 [统一方案](../03-data/05-data-repair-and-1h-filter.md) 为准，以下旧描述不代表已按新设计运行。

产品名称是 LP Atlas。要打造的是高效的工业级工具，不是先解决字段对齐。教程、开源仓库和聚合站只作借鉴，不是产品边界。

扫描层覆盖已接链上目标协议的全站池，先发现再按条件过滤后展示。同时持仓上限可配置；教程里建议的 7 到 10 个池只是操作建议，不限制扫描和展示。Uniswap Explore、Meteora、Pancake、Barker、Revert、LP Agent、Krystal 以及 vfat 只作前端界面参考和信号对照；生产扫描走官方索引或自建窗口，不把页面抓下来当真源，也不照抄第三方自动再平衡或托管执行。

| 清单 | 范围 |
| --- | --- |
| 正式链 | Elysium、BSC、Ethereum、Base、Solana |
| 正式协议 | Uniswap V3/V4、Pancake V3 与 Infinity、Meteora DLMM、Raydium CLMM |

## 全期产品框架

产品按四层往上叠。结构必须一次设计到位，避免后面打补丁。

| 层 | 内容 | 现在怎么处理 |
| --- | --- | --- |
| 第一层 扫描看板 | 全站数据接入、过滤、筛选、排序。必须做扎实 | 第一期实现和验收的门 |
| 第二层 只读仓位 | 连接钱包，读出已接入协议上已有的头寸，不限于本产品开过的仓 | 先完成设计，扫描验收后实现 |
| 第三层 开仓页 | 四套模板；由用户在页面上签名提交，产品只组交易，不代持、不默认自动下单 | 先完成设计，扫描验收后实现 |
| 第四层 自动执行 | 自动开仓、自动调仓复投；同时持仓建议可配置 | 暂缓，须用户另行确认后再做 |

## 第一期范围

- 只做全站扫描和过滤看板：数据接入、过滤、筛选和排序必须做扎实。
- 手动刷新；不连接钱包，不提交交易，不另做登录。
- 后台每 30 分钟扫描已确定并获准实现；与手动刷新共用管线，已有刷新则跳过。提醒、Fee 对 IL 列、自动开仓与默认自动重挂仍暂缓。
- 钱包、只读仓位和开仓页的完整设计已写入标准，按用户签名上链来设计；实现等扫描验收通过后再做。第二层须发现已有协议头寸；缺资产时自动兑换再开仓；授权默认按含滑点缓冲的本次上限；调仓以价格为准、时间冷却可调且默认 0；滑点可调默认 0.5%；同时持仓建议默认 10。
- fees APR 只用窗口内实际归 LP 的手续费年化，不用费率档乘成交量。

## 落地顺序

1. 跑通 Elysium 上的 Uniswap V3 与 Uniswap V4。Elysium 是 Uniswap 官方部署链，但没有官方索引，已定窗口（1 小时、2 小时、4 小时、6 小时、24 小时、3 天）必须自建并如实展示，不得空着，也不得用其他窗口冒充。2026-11-14 用户取消本期归档 RPC、逐池金额对账与剩余缺档归因前置条件，Elysium 第一期验收完成；读状态仍优先用官方 StateView。联调允许使用官方公开节点 https://rpc.elysium.kinetiq.xyz，并标明这是临时公开源（public_temporary）。
2. Robinhood Chain 上的 Uniswap V3 与 V4 已于 2026-11-14 获单独授权并生产拉数，规则见 [08-robinhood-venue.md](../04-standards/08-robinhood-venue.md)。这是当时的例外，不改变其他场所须单独授权才能启用的规则。
3. 下一步先接 Solana：先做 Meteora 的动态流动性做市（对照 DLMM），再单独做 Raydium 的集中流动性（对照 CLMM）。必须先补非以太坊底座，再写适配器；标准未宣布启用前，不得改成已启用，也不得拉生产数据。详细边界见 [17-solana-venue-architecture-2026-11-20.md](../05-operations/17-solana-venue-architecture-2026-11-20.md)。2026-11-20 用户确认先更新 Solana，BSC 暂时不动。
4. BSC 上的 Pancake V3 与 Uniswap V3，以及随后的同链 Pancake Infinity 与 Uniswap V4、Ethereum 与 Base 的 Uniswap V3/V4，仍在正式清单内，但暂时不动，须另行授权后再启。Solana 上的 Meteora DAMM V2 仍为后期协议，不提前实现。各链接入时用当时的现行官方协议。
5. 扫描验收通过后实现开仓层。自动开仓仍暂缓。
