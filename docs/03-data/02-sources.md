# 数据源与指标借用

> 2026-11-16已确认RedStone Push统一报价合同见本文末节及方案13第9/9.10节。涉及主资产报价的旧描述已被该合同取代；报价层及历史纠错已部署，本轮统一验收及未恢复限制以05-roadmap“美元计价修复”为准。

> 最新设计：窗口为 1H、2H、4H、6H、24H、3D，小时档保留 4 天；实施状态及旧记录以 [统一方案](../03-data/05-data-repair-and-1h-filter.md) 为准，以下旧描述不代表已按新设计运行。

执行与头寸状态的真源一律是私有 RPC 加官方合约。生产扫描走官方索引或自建窗口。禁止把参考站的 HTML 抓下来当真源。能从链上自己算出相同信号的，就不依赖这些站是否在线。暂时算不清的，可用公开接口作旁路对照，入场前仍用私有 RPC 复核。第三方自动再平衡和托管一键开仓不用。

Uniswap Explore、Meteora、Pancake 的官方界面，以及 Barker、Revert、LP Agent、Krystal、vfat 这些聚合站，都只作前端界面参考和信号对照，不是头寸和成交的真源，也不是扫描数据源。看板和后续开仓、仓位页的布局、筛选与信息层级可以对照这些站点，但要做成自己的产品界面，不照抄托管执行。

## 第一期接入策略

- 第一期先接 Elysium 上的 Uniswap V3 与 Uniswap V4。没有官方索引，已定窗口（1 小时、2 小时、4 小时、6 小时、24 小时、3 天）必须从成交日志自建并如实展示，不得空着，也不得用其他窗口冒充。
- 生产与验收必须使用带归档、能补历史日志的 RPC，并优先用官方 StateView 读当前状态，不要只扫日志。端点可配置，预留主备。
- 联调阶段允许使用官方公开节点 https://rpc.elysium.kinetiq.xyz，并标明这是临时公开源（public_temporary）。公共节点不能当作生产或验收主源。
- 节点限流、查询范围限制或挂掉时必须明确报错，不能拿过期表冒充新数据。
- 社区索引（如 Envio）只作备源，必须标成非官方，挂了同样要报错。
- 每个数字标明来源和截止时间。当前未结束的小时要标成未完成。
- 接到 BSC 时再启用官方索引：Pancake V3 用官方 subgraph；Uniswap V3 用带密钥的 The Graph 部署或自托管官方 subgraph，不用免费公开示例端点当生产源。Infinity 与各链 Uniswap V4 若暂无官方生产索引，窗口自建。

## 指标怎么来

Elysium 美元计价沿用官方 USDC 锚点及原小时结束区块的池价。原价格图无法给成交代币计价时，只补读目录中相关的 V4 报价路径；无当小时成交的桥也可用，但新增桥须在该历史区块有非零活跃流动性，不按代币名称认定锚点，不覆盖已经有效的美元金额。旧小时补价复用已存原币成交和 LP 费用，不重拉 Swap；没有通路或没有有效桥时仍留空。执行状态见方案 05 第五节。

| 指标或信号 | 优先做法 | 说明 |
| --- | --- | --- |
| 池 TVL、费率、当前价、tick / bin、是否在区间 | 自建 | 直接读池合约与头寸 NFT，是热路径必须自有的状态 |
| 手续费、成交量、fees APR | 能自建就自建 | 用 swap 事件和流动性自己算；聚合站可作发现排序和交叉核对 |
| Fee vs IL、区间效率、LP range | 自建 | 这是入场与离场的核心信号，不应该只依赖站上的一个数字 |
| 收益模拟、发现榜单 | 可借用，再自建 | Revert、vfat、Barker、Krystal 可用来找池和对照计算；稳定后用自己的公式接管 |
| 农场奖励、积分、外部补贴 | 先借用 | 这类信号常常只在聚合层出现，短期可以从站上接入，但不进热路径 |

## 主资产美元来源合同（2026-11-16确认）

2026-11-16用户已确认的报价合同见[方案13第9/9.10节](../05-operations/13-dollar-valuation-repair-review-2026-11-16.md#9-统一报价层落地设计本轮方案正文)，取代此前Alchemy作为主源、Hyperliquid作为主源及10分钟有效期的调查建议；原文相关旧计价描述只说明旧生产状态，不作本次实施规则。2026-11-16用户追加授权停采集更新后恢复，RedStone代码与迁移012已部署，17:08补丁加载至API27116；包装映射、完整保留期及本轮真实验收已核，未恢复记录和精确费用限制保留；唯一进度见05-roadmap“美元计价修复”。

- 在现有四层内实现统一报价能力，不另起服务/扫描管线。主源RedStone Push，两条已启用业务链共用ETH/USD、HYPE/USD；报价按资产＋来源＋目标时间共享，池状态、目录及游标按链隔离。各链采集RPC维持实际配置，本方案不自动迁移到Alchemy；Alchemy Prices API仅可选适配，本期不接Chainlink备源，不假设备源资产覆盖对称。
- 接受Push心跳/偏差的最新有效价，如实记录publishedAt；不要求每轮五分钟新价，不混用早期10分钟有效期与六小时心跳，不靠加频读取刷新预言机。源链历史块必须block.timestamp <= targetAt，报价publishedAt也不晚于targetAt；五分钟桶命中仍核时间，禁止跨链套区块号、未来最近块和当前价回填历史。
- 仅已验证1:1包装的WETH/WHYPE同价；本轮仅核定Elysium官方WHYPE和Robinhood官方WETH（地址及相同运行代码证据见13第9.12节），其他映射未启用；同名币、质押衍生币及任意桥接币不得自动串价。根价先锁定，池推导不得回写，同一计算内原生/包装引用同一值。
- 复用原币累计及repair-hour按小时重建价格表，重估旧版本非空错误金额，不重拉全部Swap、不统一倍乘。TVL仍依赖业务链历史储备；修复不得覆盖较新续接，失败保留旧值及旧计价版本。金额、来源引用/计价版本、链发布版本沿小时事务提交。
- 报价失败不得阻止原币成交、费用和覆盖提交；美元缺失不补0、不把陈旧金额标成当前完成。价格使用独立超时与请求资源，不继承360秒日志等待，有限尝试后快速结束，不与日志或另一资产互相阻塞。关闭新报价不得静默恢复已证实错误的旧多跳为正确值。
- 不改变费用算法、窗口、保留期、准入、前端布局或未启用场所。实施/部署授权与文档合同确认分开记录，不因本节写入就标记代码或金额验收完成。
