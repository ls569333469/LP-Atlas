## 1. 最终要回答的问题

对过去几天曾满足过滤条件的全部池子复盘：

1. 哪些成交量、手续费、资金效率变化，能识别资金开始起量？
2. 起量时属于上涨、横盘、转弱，还是现有数据无法判断的插针行情？
3. 同一个信号，窄区间滚动与宽区间持有，哪种实际模型净利润更好？
4. 在区间内赚到的手续费，能否覆盖相对持币的无常损失与操作成本？本金是否实际增加？
5. 热度衰减到什么程度退出，出区间后是否值得重挂、复投或迁移？

最终给用户的主表直接写：**策略、起始本金、交易次数、手续费、库存损益、成本、最终资产、净利润，以及结果能覆盖多少池。** 不只交付指标相关性，不只展示KNTQ或盈利交易，也不将所有独立机会的利润相加冒充一份资金收益。

## 3. 样本全集与时间边界

### 3.1 主样本

- 优先复用已冻结的北京时间 **2026-11-11 13:00—11月13日13:00，48个完整小时**。这就是前两轮共同的全市场输入。
- 原导出141候选池，其中138池曾在完整小时内符合条件，另3池只有未完成小时观察。这3池单列，不凑入历史交易样本。
- 历史准入沿用 **1H TVL≥$1,000、成交量≥$100、普通LP核心手续费≥$10**，并核对完整小时、覆盖与费用状态。不是手续费占比，不是标称费率乘成交量。
- 历史任意一小时合格便纳入池全集；进入样本后保留其后来退热、不再合格、出区间和撤池的资料，不仅从当前看板倒选幸存池。
- 先覆盖全部历史合格池，再评估附加量能规则。不能先只留2倍放量子集，再宣称已对全部合格池跑策略。
- 按 `chainId + protocol + poolId` 识别池；相同代币不同池分别计算，代币汇总列出去重池数，不按名字合并。

## 4. 先发现量能，不先限定“盈利指标区间”

仅使用信号时点及之前的数据，记录：

| 指标 | 定义/用途 |
|---|---|
| 资金效率 E | 1H成交量 / 该小时末TVL，描述周转热度 |
| 费用强度 Q | 1H普通LP费用 / 该小时末TVL，描述全池单位资金收费密度 |
| 成交加速 | 最近1H成交 / 此前2个完整小时的小时均值 |
| 费用加速 | 最近1H普通LP费用 / 此前2个完整小时的小时均值 |
| 效率变化 | 当前E相对前1H的变化；同时列成交和TVL变化，识别缩TVL造成的假性升温 |
| 价格与端点波动 | 1H、4H方向及已有端点振幅/RMS；不冒称小时内高低点 |
| 持续性 | 连续活跃、前后小时收费与成交是否延续；未来部分只作评价 |

比较三类入场：原三准入基线；相对前2H均值的1.5/2/3倍起量；起量后再次确认仍活跃。成交与费用联合上升、效率上升分别做对照，确认附加条件有没有增益。此前为0的新起量单列，缺档不当0，倍率分母为0时不硬造倍数。

效率先按 `<0.5、0.5–1、1–3、3–10、≥10` 展示分层，不直接设效率≥1门槛。不先排除大涨、不因某次盈利事后修改阈值。参数均是研究配置，首次触发与持续触发分开；同池重复小时、相关参数不能当独立证据。先看样本量、后续收费和净额，再决定可保留的候选规则。

## 5. 状态判断与策略对照

以下是待验证的研究定义，不是已经确定的生产规则。价格方向统一成目标资产相对报价资产的方向；同时保留报价资产兑美元变化。

| 状态 | 本轮可判断内容 | 策略对照 |
|---|---|---|
| 起量上涨 | 1H与4H均上涨；轻微波动区间另列，不事后按未来上涨命名 | 对称区间与向上偏置（下20%/上80%）比较 |
| 起量横盘 | 1H变化绝对值≤2%、4H变化绝对值≤4%的端点组 | 对称窄区间、宽区间比较 |
| 反弹/转弱 | 1H与4H方向不一致，或下跌 | 单独对照，不与上涨组混成一个均值 |
| 插针 | 小时端点不能证明盘中刺穿后回归 | 有细粒度路径才回测；当前标未执行 |
| 状态资料不足 | 缺价格/历史边界 | 保留池行和原因，不凭空分类 |

### 5.1 范围和持有

目标总宽 **1%、2%、4%、8%**；1%指总宽，不是上下各1%。实际按tick对齐，记录上下边界、相对入场价宽度、tick spacing及币量。若目标1%与2%对齐成同一区间，合并为相同实际区间展示，不能当两个独立成功策略。若无法形成入场即在范围内的有效区间，列不适用，不偷换成区间外挂单。

先以同一信号、同样本金、相同观察截止比较“仅出区间/到期退出”和“热度衰减退出”，持有上限1/2/4/6/12H。上限不是强制持满。半小时资料不足时明确未执行。

热度退出比较成交、E或Q降至入场基准50%的既有研究条件，分项与组合分别核对。旧±2%净额止损/止盈保留为旧策略对照，不暗中套给全部新策略、提前截断高收费机会。出区间仍有重新判断步骤，不能无条件重挂；小时末发现与真实首次触边不是同一种执行。

### 5.2 窄区间滚动、宽区间、资金管理

- 窄区间：出区间或热度退出后，下一可用决策时点仍满足入场信号才重挂；迁移按当时已知收费/热度选池，不按未来利润选池。原冷却1H作为可执行小时链路基线，不冒称高频机器人。
- 宽区间：同一入场信号，比较较低调整频率是否能用更长在区间时间弥补收费集中度下降。
- 固定本金出利与利润复投独立重跑路径。单策略同池不重叠；单钱包同一时刻一笔持仓，明确现金、在险资金、提取利润和已实现净额。
- 本金以 **$200为主，$1,000为容量对照**。现有本金/TVL≤5%的小额假设限制保留并列不适用，不按亏损处理；另外检查活跃区间份额，不能仅凭全池TVL判定无影响。
- 先完成单笔范围与退出的可算性，再跑滚动账户，避免拿缺档退出后继续轮换。未知在仓时停止该账户后续模拟，不能假定已经卖出。

## 6. 收益核算：两本账分开

**本金净利润 = 退出时LP本金价值 + 累计手续费价值 − 入场本金 − 执行成本。**

**相对持币净额 = LP本金价值 − 原始两币持有价值 + 手续费价值 − 执行成本。**

两者都列；前者回答赚没赚钱，后者回答手续费是否覆盖相对持币的无常损失。库存损益已经包含LP资产变化，不再重复扣一次无常损失。相同估值时点和计价单位核对；同时保留原币金额、报价币结果及美元结果，防止HYPE/USD变化混入方向判断。

手续费沿用已实盘核对的 `liquidity × feeGrowthInside增量 / Q128`，处理回绕和逐币取整；调仓先结算旧流动性，再变更。累计原币费与按小时估值、退出时估值分开，不能把重新估值重复记成新收益。

假设新仓位改变了活跃流动性，历史feeGrowth的每单位收益不能自动视为新增资金可原样拿到的收益。保留边际模型标识；活跃份额显著或无法验证影响时，不称可执行精确收益。历史边界tick未初始化、小时内清零/重初始化，必须有足够路径证据才能计算；缺证据为未知，禁止回退固定50%、本金/TVL分摊或标称费率乘成交。

成本先沿用往返50bps+$1显式假设，同时给出费用前净额及可承受总成本。固定成本、换币损耗、gas、迁移和复投的每次费用分别计入，不把真实钱包某次gas当成所有池常数，也不把“撤LP”直接等同于已兑换成美元到账。

## 7. 执行顺序与验收

执行状态只维护在roadmap，不在本文件另复制打钩清单。

| 顺序 | 必须完成的工作 | 判断标准 |
|---|---|---|
| 1 | 核对主样本、前两轮结果及费用/价格证据 | 全池清单、真实准入时间和缺口对齐；确定复用内容，避免重复采集 |
| 2 | 评估可算性，补读必要区间证据 | 沿用现有采集入口和缓存，只补缺项；先区分可补RPC数据与无法靠重试解决的tick路径问题 |
| 3 | 全池跑量能、状态、范围及退出对照 | 每个历史合格池都有结果或具体原因；按相同入场、相同可算样本配对比较，不能用不同覆盖子集直接排名 |
| 4 | 跑固定出利、复投、重挂/迁移账户 | 每套策略资金路径闭合，不重叠、不透支、不用未来数据；缺费用或退出证据时不伪造完成 |
| 5 | 统一页面与数据验收 | 从策略汇总可下钻每个池与逐笔，金额/手续费/成本/区间及时间一致，中文编码正常 |

覆盖报告必须列：历史合格池数、合格小时数、尝试/可算/未知/不适用/未到期数，以及费用/价格/路径/成本问题具体影响哪些池。先验收当前样本能支持的结果；证据不足的策略明确受阻，不把整个研究无限扩成全链取证工程，也不宣布已验证盈利。

原48H按前后24H及按池分组检查，已查看过的两段只算内部稳定性观察，不叫样本外验证。保留旧策略同输入对照及新条件筛选变化；不因最终利润好看反复调整参数。结论应能明确说明“哪些候选值得继续验证、哪些条件未体现增益、哪些因覆盖不足还无法判断”。
